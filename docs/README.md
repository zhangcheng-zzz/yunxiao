# dsh-yunxiao

适用于 DeepSeek Harness 的轻量云效工作台插件：管理云效账号与项目、处理缺陷、查看与运行流水线。配置与缓存保存在一个 JSON 文本文件中，无需数据库，也不接收消息回调或 Webhook。

## 能力

- 入口：集成到 Harness 左侧栏底部，打开后占用框架预留的右侧列；可拖拽左边缘调整宽度，浏览器记住上次宽度。
- 页面：默认进入“概览”聚合页；提供“概览 / 工作项 / 流水线 / 代码 / 测试 / 制品 / 编排 / 设置”八个页签。工作台默认以全页形态打开（覆盖中间聊天区、只保留 Harness 左侧导航），头部按钮可切回右侧栏侧栏模式且选择会被记住，跟随系统的浅色/深色两套配色。各页统一使用“固定宽度方格统计卡 + 自适应方格卡片网格”的版式。
- 概览：顶部统计卡聚合待处理缺陷、流水线总数 / 运行中 / 最近失败、启用的编排与 DSH 工作区绑定状态，点击直达对应页签；“待处理缺陷”复用工作项页的方格卡片（最多 8 条，含状态下拉、负责人、标签与草稿/处理按钮，“查看全部”跳转工作项页）；“流程编排”以方格卡片展示（启用状态着左轨、最近一次运行结果作徽章），点击卡片直接打开该编排的画布。
- 账号与项目（设置页）：顶部统计卡一览账号数 / 已配置令牌数 / 当前项目 / 工作区绑定 / 缺陷通知状态；维护多个云效组织 ID 与个人访问令牌，账号以方格卡片展示（令牌状态着左轨、当前账号带描边），点击卡片或“设为当前”切换账号；为每个账号记住当前项目，“当前项目”与“DSH 工作区绑定”两张卡在宽容器下左右并排、窄容器上下排列。
- 工作区绑定：设置页可为当前项目绑定一个 DSH 工作区（读取 Harness 工作区注册表，按账号+项目保存），绑定后可从缺陷列表或详情一键处理缺陷，也可被编排的“DSH 智能处理”节点引用。
- 工作项（缺陷）：按创建时间从新到旧分页，每页条数按工作台当前可用宽高自适应（估算方格卡片的列数 × 行数，范围 4–100，窗口尺寸变化时防抖重算并回到第一页）；按状态/负责人筛选（状态选项按项目缺陷工作流去重拉取，接口异常时退回最近缺陷结果）；列表顶部提供状态统计卡（全部/待确认/处理中/再次打开/其他状态，固定宽度方格小卡按容器自动换行），点击统计卡即可切换状态筛选；列表为自适应方格卡片网格，标题最多两行，行内展示负责人徽章与优先级/严重度/迭代标签；列表和详情中可直接修改状态与负责人，成功后自动刷新列表；“待确认”“处理中”“再次打开”的缺陷卡片使用柔和差异色；宽容器下缺陷通知配置在列表右侧并排显示，窄容器自动回落到列表下方；支持查看描述/评论/附件并以当前账号发布评论；附件与内联图片的直链有时效性，加载或下载失败时自动换取新地址重试。描述/评论中的图片与图片附件支持点击全屏预览（点击图片切换适应窗口/原始大小，Esc 或点击遮罩关闭），右键提供“预览图片 / 复制图片 / 下载图片”菜单：详情页的图片统一以 132×92 小缩略图横向排列、过多自动换行，图片附件同样以缩略图展示（文件名在缩略图下方），非图片附件保持行式列表；复制由客户端把图片统一转成 PNG 后，桌面端经宿主调用系统剪贴板写入（macOS 走 osascript，Windows 走 PowerShell Forms，不依赖浏览器剪贴板权限，也无跨域限制），浏览器环境回退 navigator.clipboard，再回退 execCommand 选中复制。
- 缺陷处理：“待确认”“再次打开”（含同义命名）状态的缺陷在列表和详情提供“草稿”“处理”两个直达按钮：读取缺陷详情后，在项目绑定的 DSH 工作区创建会话，带入缺陷标题和描述/附件中的图片（宿主侧换取直链并转 base64，最多 8 张，单张失败自动跳过；正文只保留标题，描述含文字时附在“缺陷描述”之后）。“草稿”只填入会话输入框不自动发送（优先复用工作区空白会话），“处理”新建会话直接发送；未绑定工作区时提示先到设置页绑定。
- 缺陷通知：按项目开启系统原生通知（自动识别平台：Windows 使用 Toast，macOS 使用通知中心；识别结果存入数据文件，之后不再重复判断，数据文件搬迁到其他平台时自动重新识别），可选择负责人和轮询间隔；自动检查“待确认/再次打开”的缺陷，桌面端每轮提交一条原生通知（失败时回退 Web 通知）；提供内部通知弹窗、“测试通知”“立即检查”等操作；侧栏角标与未处理数一致，处理后自动清零。
- 代码（Codeup）：组织内仓库列表（名称、路径、默认分支、最近活跃），与流水线页同款的统计条（全部/7 天内活跃/30 天内活跃/长期未活跃）、关键词回车搜索与上下分页，仓库卡片以自适应方格网格展示；按仓库查看分支与进行中的合并请求；检测无阻塞的待合并 MR 可直接合入，接口失败时提示改走云效页面。
- 测试 / 制品：组织内测试计划（用例通过率与卡点展示）与制品仓库列表，同样提供统计条、方格卡片网格与上下分页（测试按进行中/已完成着色左轨，制品按语言包/镜像与 Charts 分类计数）。这两个域的 OpenAPI 在不同组织版本间开放程度不同，接口不可用时页面给出明确提示，不影响其余功能。
- 流程编排：把云效事件与动作串成一条流。画布支持拖拽节点、端口连线（连线点两次删除）、节点参数配置；流程定义与运行记录白名单清洗后存入数据文件（节点 ≤64、连线 ≤128、每条编排保留最近 30 次运行）。运行由客户端逐步驱动：工作项状态更新、评论回写、系统通知、流水线运行、DSH 智能处理（复用缺陷“处理”通道）为真实动作；“创建合并请求 / 代码检测 / 测试计划 / 部署”为人工检查点，节点上“通过 / 终止”推进；条件分支按“是 / 否”连线分流（优先级比较、根因定位）。开启“缺陷自动触发”后，缺陷通知检查发现新增待处理缺陷时自动运行对应编排。
- 流水线：组织级列表、详情、代码源与分支、运行记录、阶段/任务与日志查看；列表顶部提供运行状态统计卡（全部/最近成功/运行中/最近失败/暂无运行，固定宽度方格小卡按容器自动换行），关键词支持回车查询；列表卡片按最近一次运行状态着色并以自适应多列网格展示；列表内点击“运行”直接弹出运行对话框（无需先进入详情）：对话框立即渲染，Codeup 分支加载后补充代码源控件，分支读取失败时仍可用流水线默认配置运行或手动填写分支，单分支代码源可输入任意分支名，未识别仓库地址时提示使用默认分支；不接收环境变量。
- 模型工具：`yunxiao_list_defects` 和 `yunxiao_list_pipelines` 两个只读工具，默认读取工作台的当前账号与项目。
- 离线回退：项目、最近缺陷列表和流水线列表写入文本缓存，OpenAPI 暂时失败时展示缓存并标记时间。

插件不提供消息回调、Webhook 接收、通知规则或后台定时采集。

## 数据存储

默认数据文件为 Harness 启动工作目录下的：

```text
dsh-yunxiao.data.json
```

它是可直接查看、备份和编辑的 UTF-8 JSON 文件，不需要数据库。写入时先生成临时文件再原子替换，避免中途退出留下半个 JSON。

重要：个人访问令牌也会保存在这个文本文件中。Host 不会把令牌返回给浏览器，但文件本身不是加密保险箱。请限制文件访问权限，不要提交到 Git，也不要放入公开同步目录。如果部署环境要求加密凭据，应改用 Harness credentials 服务或操作系统密钥存储。

## 安装与更新

以下命令均在插件仓库根目录（即本仓库根目录）执行，命令中只使用仓库相对路径。

首次安装或改动后重新安装：

```powershell
# 从仓库目录安装（首次安装、或换用另一份源码目录时执行）
dsh plugin --profile web add -w .

# 校验组合配置中出现 dsh-yunxiao
dsh --profile web --dump-config
```

卸载：

```powershell
dsh plugin --profile web remove -w dsh-yunxiao
```

注意事项：

- 所有 `dsh plugin --profile web add/remove` 命令都必须带 `-w` 参数。web profile 目录本身是一个 pnpm workspace 根，缺少它时会报 `ERR_PNPM_ADDING_TO_ROOT` / `ERR_PNPM_REMOVING_ROOT`。
- 安装是 link 形式：profile 直接引用仓库中的插件源码目录。日常只修改 `dist/index.js` 或 `dist/client.js` 后，重启 Harness 实例即可加载最新代码；仅当插件的 `package.json` 变化（名称、入口、依赖、版本元数据等影响安装结果的字段）时才需要重新 `add`。
- 安装或重新安装后，必须重启正在运行的 Harness Web/Desktop 实例才能生效。

验证组合配置中应出现：

```yaml
- id: dsh-yunxiao
  name: dsh-yunxiao
```

安装后重启正在运行的 Harness Web/Desktop 实例。左侧栏底部会出现“云效工作台”入口，侧栏折叠时显示“云”图标。工作台固定在右侧列中打开，关闭后聊天区恢复完整宽度。

## 配置

可在 profile 的 `cordis.patch.yml` 中覆盖整行配置：

```yaml
- override:
    id: dsh-yunxiao
    name: dsh-yunxiao
    config:
      dataFile: 'D:/private/dsh-yunxiao.data.json'
      apiBaseUrl: 'https://openapi-rdc.aliyuncs.com'
      timeoutMs: 45000
      cacheMaxItems: 100
```

`apiBaseUrl` 只接受 HTTPS。`cacheMaxItems` 限制列表缓存数量，范围 10–500。

## 云效令牌权限

按实际使用功能给个人访问令牌授予最小权限：

- 项目读取；
- 工作项读取；
- 使用缺陷“草稿/处理”时需要工作项读取（读取缺陷详情与附件图片直链）；
- 修改缺陷状态时需要工作项写入；
- 在详情中更换缺陷负责人时需要工作项写入，读取项目负责人候选列表时需要项目成员只读权限；
- 发布缺陷评论时需要工作项评论读写权限；
- 流水线读取；
- 手动运行流水线时需要流水线运行权限；
- 读取 Codeup 分支时需要代码库/分支读取权限；
- 查看 Codeup 仓库与合并请求需要代码库只读权限，直接合入 MR 需要合并请求写入权限；
- 查看测试计划需要测试管理只读权限，查看制品仓库需要制品只读权限（这两个域的 OpenAPI 在部分组织未开放，未开放时页面会明确提示）。

只使用查看功能时无需授予写权限。

## 开发验证

在插件仓库根目录运行：

```powershell
node --check .\dist\index.js
node --check .\dist\client.js
npm test
npm pack --dry-run
```

实现遵循 Harness 的可安装组合包结构：`dsh.bundle.patch` 挂载 Host 插件，`dsh.client` 在 Web 表面即时加载无框架 Client。参考：[DeepSeek Harness 插件基础](https://deepseek-harness.github.io/deepseek-harness/develop/basic/)。
